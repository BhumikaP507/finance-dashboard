# Finwise — Finance Dashboard

A responsive personal finance dashboard built with React, Vite, Recharts, and Lucide icons.

## Features

- Income, expense, and balance overview with cash-flow and spending charts
- Search, filter, and sort transactions
- Add, edit, and delete transactions
- Export transactions to CSV
- Theme and transaction persistence with `localStorage`
- Responsive desktop, tablet, and mobile layouts
- Sample data is stored in the browser; no backend or account authentication is configured

## Run locally

```bash
npm install
npm run dev
```

Vite prints the local URL after startup (usually `http://localhost:5173`).

## Production build

```bash
npm run build
npm run preview
```
